# Codex 簡易プロンプト：ホーム背景（下の2カードの裏まで届く全画面版）

ブランチ `codex/ui-v3`、作業フォルダ `.worktrees/ui-v3`（Codex が自分で作る。手順は `docs/codex/UI_V3_PROMPT.md` の冒頭）。触るのは画像と記録だけ。コードは変更しない。ビルドしない。

## 問題
ホーム画面は、上から「ヘッダー → 部屋の絵（`bg/room-home`、猫が立つ）→ 2枚のカード（旅するモビー／今日の出会い）→ 下端の独立ナビボタン」と並ぶ。部屋の絵は1179×1900で、カードの裏までは届かない。そのため部屋の下に無地のクリーム色の余白ができる（ナビがバーから独立ボタンに変わり、さらに目立つ）。

## 作るもの
`app/assets/ui/bg/room-home-full.png`（**1179×2556、不透明**）。ホーム画面の**全面**に敷く1枚絵。`bg/room-home` の続きとして、床がカードの裏・ナビボタンの裏まで**途切れず**続く。

- タッチ・色味・家具は `bg/room-home.png`（C の修正後）と完全にそろえる。**写真のような質感・強い陰影は禁止**（`UI_FIXES_PROMPT.md` の絵のタッチ）。
- 縦位置は目安（画面は約 393×852pt ≒ 1179×2556 として）：

| 縦位置 | 内容 |
|---|---|
| 0〜10% | ヘッダーが重なる。壁・カーテンレールなど**なだらか**に。 |
| 10〜24% | 壁・窓・棚・ソファ。右上（縦 12〜30%、右寄り）は**単純な壁を空ける**（ログイン記録ボタン用）。 |
| 24〜40% | ソファ・キャットタワーの足元〜床の始まり。 |
| 40〜68% | **床とラグ。猫が立つので中央は何も置かない。**ラグは左右に床が見える大きさに収める。 |
| 68〜90% | **2枚のカード（各約128pt の高さ、横幅いっぱい）の裏。** 何も置かず、模様・板目・明暗の差を最小に。**やわらかく平らなオレンジの床**。カードの縁が読める明るさ。 |
| 90〜100% | 4つの独立ナビボタンが浮く帯。**完全に平ら・低コントラスト**。左右の端にも物を置かない。 |

- 右下（縦 60〜70%、右端）のカメラボタンの位置も空ける。
- 床は下に向かって**板目を消して**単純にする。下端で色が止まらず、そのまま画面の端まで続く（段差・帯・縁を作らない）。
- 左右の端で絵が切れても不自然でないこと（アプリ側は cover で表示するため、端が少し切れることがある）。
