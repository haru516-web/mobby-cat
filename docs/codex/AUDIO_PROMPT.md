## 1. 世界観

ねこモビーは、現実の暮らし（歩数・電池・暦・月）がそのまま猫との出会いになる、やさしいコレクションゲーム。ふわふわ・あたたかい・ぷっくり。毎日開いても疲れない、小さく可愛い音にする。

- BGM: ポップで軽快、リズミカル（2026-10-25 に「おだやか・強いビートなし」から変更）。軽いキック・クラップ・16分のハイハット、跳ねるベース、裏拍のウクレレ刻み、マリンバとやわらかいリードの旋律。歌・ボーカル・ファンファーレは使わない。長調を基本に、気持ちよく何度も聞ける短い旋律。
- 効果音: 木・布・紙・小さな鈴のようなやわらかい音。耳に刺さる高音、電子的なビープ、ゲームの派手なコイン音は使わない。
- 猫の鳴き声は、本物の録音ではなく、**合成または自作の短い「にゃ」風の音**にする。権利が不明な素材は使わない。
- 使った素材・ツール・ライセンスを `docs/audio-credits.md` に記録する。

## 2. 形式とミックス

- 置き場所: `app/assets/audio/bgm/<ID>.m4a` と `app/assets/audio/sfx/<ID>.m4a`。**ファイル名は下表の ID のとおり。**
- 形式: m4a（AAC）、モノラル可（効果音）、BGM はステレオ 128kbps 前後。
- 容量: BGM は1曲 1MB 以内（合計 3MB 以内）。効果音は1つ 50KB 以下。
- BGM は**継ぎ目なくループ**すること（先頭と末尾に無音やクリックを入れない）。
- 音量は小さめ前提（アプリは歩きながら使われる）。BGM は -20 LUFS 前後、効果音は -16 LUFS 前後、ピークは -1 dBFS 以下。
- アプリは BGM を 0.8 秒でクロスフェードで切り替え、BGM 音量の初期値は 40%、効果音は 70%。この音量でちょうどよく聞こえるように作る。

## 3. BGM（3曲）

| ID | 使う場面 | 雰囲気 | 長さ |
|---|---|---|---|
| `bgm_home` | ホーム・図鑑・世界・ショップ・設定・お知らせ（ふだんの画面すべて） | 日だまりの猫部屋。明るく弾むポップ（BPM 110 前後、軽く跳ねる）。 | 60〜90 秒ループ |
| `bgm_deai` | 「出会い」タブ（今日の候補を選ぶ画面） | わくわく。`bgm_home` と同じ楽器で、サビは4つ打ちでいちばん元気（BPM 125〜130）。 | 45〜60 秒ループ |
| `bgm_welcome` | 初回の相棒選びとチュートリアル | 「はじめまして」。軽いリズムから始まり、楽器が増えて盛り上がる（BPM 115 前後）。ループで自然につながること。 | 30〜45 秒ループ |

## 4. 効果音（12個）

「いつ鳴るか」はアプリ側で決めてある。ボタン類は押した瞬間に `sfx_tap` が鳴り、その直後にイベントの音（`sfx_pick_*` など）が重なることがある。**重なっても濁らない**よう、短く、周波数を散らす。

### 4-1. 共通操作

| ID | 鳴るとき | 長さ | 方向性 |
|---|---|---|---|
| `sfx_tap` | **すべての操作**（ボタン・×・タブ・スイッチ・一覧のマス・文字のリンク・チュートリアルの「つぎへ」）。ボタンの種類で音を分けない（2026-10-25 に1つへ統合） | 約 0.25 秒 | スライムを引っぱって離したような「ぷよっ」。小さく上がる2音。下がる音は不正解に聞こえるので使わない |
| `sfx_error` | 失敗の通知 | 0.15〜0.2 秒 | 低めのやさしい「ぽこ」。責めない音 |

### 4-2. 猫とのふれあい・出会い

| ID | 鳴るとき | 長さ | 方向性 |
|---|---|---|---|
| `sfx_pet` | ホームで猫をなでた（連続でなでる） | 0.15〜0.3 秒 | 小さな「にゃ」風の合成音。3パターンあるとよい（`sfx_pet` を1ファイルで済ませるなら、ピッチが自然にばらつく音） |
| `sfx_welcome` | 相棒を選んで「はじめる」を押した | 1.0〜1.5 秒 | 鈴が上がっていく、はじまりのジングル |
| `sfx_bell` | （予約）毎日20時の出会いが届いた | 0.8〜1.2 秒 | ベルのやさしい2音 |
| `sfx_matatabi` | またたびを使って候補が増えた | 0.4〜0.6 秒 | しゅわっと葉がひらく音 |
| `sfx_pick_free` | 今日の無料の1匹を迎えた | 0.8〜1.2 秒 | うれしい小さなファンファーレ（鈴と木琴） |
| `sfx_pick_extra` | お迎え券で追加の猫を迎えた | 0.6〜0.9 秒 | `sfx_pick_free` より短く軽い |
| `sfx_pick_special` | 条件で出会った特別な猫を迎えた | 1.5〜2.0 秒 | `sfx_pick_free` を少し豪華にした、きらきらした音。この音だけは特別感を出してよい |
| `sfx_gift` | （予約）7日連続のお礼など、プレゼントをもらった | 0.8〜1.0 秒 | 包みを開ける軽やかな音 |

### 4-3. 撮影・チュートリアル

| ID | 鳴るとき | 長さ | 方向性 |
|---|---|---|---|
| `sfx_shutter` | 撮影した | 0.15〜0.25 秒 | やわらかい機械式シャッター。本物のカメラ音の録音は使わない |
| `sfx_saved` | 写真を保存した | 0.3〜0.5 秒 | 「ちりん」と小さく |

## 5. 届けるとき

1. `app/assets/audio/bgm/` と `sfx/` に 15 個の .m4a を置く（`.gitkeep` は残してよい）。
2. `app/src/data/audioAssets.ts` の `AUDIO` に、置いたファイルの `require` 行を足す。
3. `docs/audio-credits.md` に、各音の作り方とライセンスを書く。
4. 一覧表（ID・秒数・容量・ループの有無）を `docs/audio-manifest.md` に書く。
