## 1. 何が問題か

今の `traveling-mobby` は、赤茶の短毛マッカレルタビー＋リュック・カメラ・コンパス。**ふつうの猫の1匹に見え、アプリの看板「世界に1匹だけの旅猫」らしい特別感がない。** ホーム・世界タブ・撮影・記念カードの主役になる子なので、**一目で「この子だけ別格」と分かる**ものにする。

## 2. 作るもの

**1匹だけ。** ファイル名・ID・名前（`traveling-mobby`／旅するモビー）は変えない。

### 守る条件
1. **既存221匹のどれとも、サムネイル（256px・512px）で見間違えない。**
   - 毛色・模様・毛の長さ・耳・顔つき・体のバランスのうち、**3つ以上が同じ猫がいてはいけない**。
   - まず221匹を毛色グループ別に並べて、**空いている領域**（まだ誰も使っていない毛色・模様・シルエット）を確認し、そこから選ぶ。確認画像は `assets/cat-mobbies/review/traveler-*.png`、検討結果は `assets/cat-mobbies/review/traveler.md` に書く。
2. **特別感の核を1つ決める**（案から選ぶか、同等のものを提案）。
   - 案A: 毛そのものが特別。光を受けると金やパールに見える特殊な毛色（実在の猫にあり得る範囲の質感。現実離れしすぎない）。
   - 案B: 顔や体に**この子だけの印**がある。例: 額やおなかの、コンパスローズや星の形の白斑。
   - 案C: 旅の象徴がシルエットを変える。例: 長いたなびくスカーフ、特徴的な耳飾り。ただしレンズとボタンを隠さない。
   - 小物は**多くても2つ**。「リュック＋カメラ＋コンパス＋スーツケース」のような詰め込みはやめる。
3. **小さく見ても特別に見える**: ホームのカード（約120px）でも、色の面か輪郭の1点で目を引くこと。
4. **「伝説」の格にふさわしい品**: かわいさは保ちつつ、他のどの猫より少し神秘的・上品に。

### モビーの型（崩さない）
`docs/codex/MOBBIES_V2_PROMPT.md` の「共通仕様」と同じ。ずんぐりした丸みのある四角い頭と体が一体。片目（画面左・生体の猫の目）、画面右にカメラレンズ、胸元の左下に十字キー、右下に黒い丸ボタン2つ。リアルな毛並み。1254×1254の透過PNG。文字・透かしは入れない。参照画像は `assets/cat-mobbies/characters/bengal.png` と `ragdoll.png`（毎回使う）。

## 3. 進め方

1. 221匹の空き領域を調べ、**3案**を `traveler.md` に書く（毛色・特別感の核・小物・似ている最も近い猫とその違い）。
2. 3案とも1枚ずつ試作し、221匹のうち最も近い猫5匹と並べた確認画像を作る。サムネイルで見分けがつくか確認する。
3. **一番「特別」に見える1案を選んで本番にする。** 選ばなかった案も `review/` に残す。
4. 型が崩れていないか確認（目がレンズ以外に2つ以上、ボタンの数違い、背景が透過でない、文字入りは作り直し）。
5. `new/manifest.json` の `traveling-mobby` の `sha256`・`bytes`・`prompt` を更新し、`"regen": true` と `"regenReason"` を書き換える。プロンプトは `provenance/prompts-traveler-v2.md` に残す。
6. コミットして `git push origin codex/new-mobbies-2`。

## 4. やらないこと

コード（`app/**`）・UI画像・他の猫の画像の変更。ルートのフォルダでの作業。ID・名前・ファイル名の変更。アプリへの組み込み（こちらで行う）。
