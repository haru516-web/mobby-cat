## すでに決まっていること（変えない）

- 製品の仕様: 出会いの日は20時から次の20時まで。「今日」タブは、前日の20時から当日の20時までの候補。入れた日の20時より前に始めたときは、最初の出会いを20時まで作らない（`installLock`）。無料でひらけるのは3匹、お迎えは1日1匹、またたび・お迎え券・パスの数と値段。
- 確率の説明: 購入した瞬間の抽選はない。候補は20時に届く時点で決まり、購入では変わらない。7匹以上そろった日は、同じ確率で6匹が選ばれる。またたびは、ひらける数を増やすだけで、どの候補をひらくかは選べる。**Apple の質問票への回答と審査メモは、運営者が決める**ので、あなたは、コード・アプリ内の文言・文書の食い違いだけを直す。
- 画面の文言は日本語で、既存の言い回し（です・ます）に合わせる。デザインの画像・色・レイアウトの方針は変えない。
- Git の運用: 私（Claude）の作業ブランチは `feature/account-server`。あなたは `codex/prelaunch-fix` だけにコミットし、私のブランチへマージしない。
