「にゃっコレ」（iOS、Expo / React Native、サーバーは Cloudflare Workers + D1）を App Store に出す前の、**最後の徹底監査**。**監査だけ**を行い、コードや画像は直さない（報告書を書く）。同じ観点で Claude も別の監査をしている。突き合わせは、両方そろってから私がやる。

ブランチ `codex/prelaunch-audit`（`feature/account-server` の先頭から分岐。作成済み）。**worktree はあなた（Codex）が作る**。作業フォルダは **`D:\mobby-cat\.worktrees\prelaunch-audit`**。

```bash
git -C D:/mobby-cat worktree add D:/mobby-cat/.worktrees/prelaunch-audit codex/prelaunch-audit
```

そのフォルダの中だけで作業し、`D:\mobby-cat` 本体や他のブランチ・worktree は触らず、ブランチも切り替えない。**ビルド（`eas build`、`expo run:*`、Xcode）は行わない。** デプロイ（`wrangler deploy`）、本番 DB への書き込み、課金・通知・外部サービスへの実リクエストも行わない。型チェック・lint・テスト・ローカルの Web 表示（`npm --prefix app run web`）は、してよい。

**変更してよいのは、報告書 `docs/audit/codex-prelaunch-2026-10-30.md` だけ。** 他のファイルは変えない。

## 観点（すべて見る。各観点の最後に「異常なし」でも、見た範囲を書く）

1. **審査（App Store Review Guidelines）**
   1.2 / 2.1 / 2.3 / 3.1.1 / 3.1.2 / 4.0 / 4.2 / 5.1.1 / 5.1.2 / 5.1.3 / 5.1.5。ダミー表示、未完成の画面、ボタンを押しても何も起きない所、課金の説明（自動更新の価格・期間・解約の案内の文面）、「購入を復元」、アカウント削除、年齢区分とガチャ・確率表示（出会える確率や条件の開示が必要か）、レビューで試せない機能がないか。
2. **プライバシーと法務**
   アプリが実際に端末から送る情報（位置、歩数、電池、端末の識別子、記録のクラウド保存、購入）を、コードから洗い出し、`docs/app-store-privacy.md`（Appのプライバシーの回答）、公開ページ（`server/src/privacyPolicy.ts`、`legalNotice.ts`、`terms` 相当）、`app.json` の許可文と**一つずつ突き合わせる**。足りない・食い違う記載、`PrivacyInfo.xcprivacy`（Required Reason API: UserDefaults、ファイルのタイムスタンプ、ディスク容量、起動時間 など）が、使っているライブラリ込みで満たされているかを、`app/node_modules` の各ネイティブモジュールを見て確かめる。特定商取引法の表示、年齢・未成年の課金上限の扱い。
3. **サーバーの安全**（`server/src`）
   認可（他人のアカウントの記録・残高・購入に触れないか）、入力の検証、Apple の署名検証（JWS の鎖、bundleId、環境、失効、返金）、二重付与・競合（D1 の同時書き込み）、レート制限の抜け、エラー時に内部情報が漏れないか、シークレットの扱い（`wrangler.toml`、ログ）、CORS・ヘッダー、公開ページの XSS、DB のマイグレーションの順序と、本番に流す手順の抜け。`npm test` の網羅の薄い所。
4. **データの正しさと壊れにくさ**（`app/src/core`、`services`）
   セーブ・読み込み・クラウドの上書き・機種変更・端末の時計の操作・日付の境目（20時、タイムゾーン、夏時間）・連続ログイン・お迎え券とまたたびの残高・パスの期限。マイグレーション（古い記録の形）、容量・件数の上限、同時に2つの更新が走る競合。
5. **安定性と性能**
   起動時間、メモリ（画像 `require` の数と大きさ、`uiAssets.ts`）、アニメーションの負荷（特に、ひらく演出で6匹が同時に動く画面）、タイマー・購読の解除漏れ、例外の握りつぶし、通信なし・遅い通信・サーバー停止のときの動き、権限を断ったとき・あとから変えたときの動き。
6. **アクセシビリティ・表示**
   読み上げ名、タップ領域（44pt）、文字サイズの拡大（Dynamic Type、`allowFontScaling`）、コントラスト、「視差効果を減らす」、画面の小さい端末（iPhone SE、375×667）と大きい端末、ノッチ・ホームインジケータ、横向き、ダークモード（`userInterfaceStyle: light` で固定されているか）。
7. **ビルド・設定・依存**
   `app.json` / `eas.json` の設定（bundleId、権限の文言、`supportsTablet`、プラグイン）、`package.json` の依存（未使用・重複・脆弱性: `npm audit`）、`expo-doctor`、環境の切り替え（開発用の機能が `__DEV__` で本番から消えるか。`__DEV__` の外に出ている開発用の入口、テスト用のURL・ID・ログ出力がないか）、`.gitignore` と、コミットに紛れた秘密情報（鍵、`.p8`、`.dev.vars`、トークン）。
8. **素材・権利**
   画像・音・フォント・ライブラリのライセンスと出典（`assets/ui-records/provenance/`、`app/assets`、クレジット画面）。他社のロゴ・商標・実在の人物・動物の品種名の扱い。アプリアイコン・スクリーンショットがガイドラインに合うか。
9. **文言と日本語**
   誤字、旧名の取り残し、敬体と常体のゆれ、改行の崩れ、存在しない機能の案内、ストア用の説明（`docs/app-store-listing.md`）と実際のアプリの食い違い。
10. **テスト・手順**
    サーバーのテストで守れていない所、アプリ側に自動テストが無い重要な処理、`docs/release-checklist.md` の手順の抜け・順番の誤り（例: 本番 DB にマイグレーションを流す前にデプロイしない）、TestFlight で人が見るべき項目の洗い出し。

## 実行して確かめるもの（結果を報告書の表にする）

`npm --prefix app run` の型チェック（`npx tsc --noEmit`）、`npx eslint .`、`npx expo-doctor`、`npm audit --omit=dev`（app と server の両方）、`npm --prefix server test`、`npx tsc --noEmit`（server）。lint のエラーは、**ルールごとに件数を数え**、バグにつながるもの（例: `react-hooks` のルール）と、見た目だけのものに分ける。可能なら、Web 表示（375×812 と 375×667）で、起動 → 相棒選び → ホーム → 出会い（開発用メニューの「今日の候補を試験用に作る」）→ 3匹ひらく、を一通り操作して確かめる。

## 報告書の形式

`docs/audit/codex-prelaunch-2026-10-30.md`。日本語。重大度は **A＝ビルド・審査の前に直す／決める、B＝公開前に直したい、C＝公開後でよい**。各項目は、次の形で書く。

- **場所**（`ファイル:行`）、**何が起きるか**（再現の手順か、具体的な入力と結果）、**直し方**（直す箇所と方針）、**確かさ**（コードを読んで確認した／実行して確認した／推測）。
- 根拠のない指摘は書かない。推測は推測と書く。前回の報告との**重複は、新しく書かず「前回 A-03 と同じ」と参照する**。
