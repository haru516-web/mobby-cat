# Codex 作業プロンプト（UI画像アセット生成）

作業ブランチ: `codex/ui-assets`（`main` から分岐）。このブランチで画像だけを追加する。**コード（`app/src` 等）は変更しない。**

---

あなたは iOS 向けコレクションゲーム「ねこモビー」の UI 画像アセットを作る担当です。
アプリはボタン・カード・枠・タブ・アイコン・背景をすべて画像で構成します（コードで色や角丸を描画しません）。そのため必要な画像をすべて生成してください。

## 読むもの
1. `docs/game-design.md`（企画・仕様）
2. `docs/ui-reference/01-home.webp`, `02-zukan.webp`, `03-deai.webp`, `04-world.webp`（目標とするUIの見た目。この4枚の質感・配色・形を再現する）
3. `docs/codex/ASSET_LIST.md`（作るべき画像の完全リストとサイズ。ここに書かれたファイル名・サイズを厳守）
4. `assets/cat-mobbies/README.md` と `assets/cat-mobbies/provenance/*.md`（既存の猫モビー素材の作り方。画像生成は同じ built-in image_gen を使う）

## ビジュアルルール
- 世界観: ふわふわ・あたたかい・ぷっくり立体。やさしい生成り色の紙質感。参照画像と同じ系統。
- 配色: クリーム `#FFF8F0` / こげ茶 `#4A3B32` / オレンジ `#F08A5D`〜`#F28B20` / 緑（またたび）`#5E9B3F` / 水色（レア）`#BFD8FF` / 薄紫（限定）`#E1D4FF` / 金 `#E5A23B`。
- 形: 大きな角丸、やわらかい落ち影（下向き・低コントラスト）、細い白ハイライト。肉球・猫耳・葉のモチーフを控えめに。
- 猫モビーの識別要素は既存素材と同じ（片目がカメラレンズ、胸元の十字キー、丸ボタン2つ）。UI画像で猫を描く場合のみ使い、既存の `characters/*.png` を再生成しない。
- **文字は焼き込まない**（`ASSET_LIST.md` の brand/ 以外）。ボタン・バッジのラベルはアプリ側で描画するため、中身は空にしておく。
- 全アイコンは同一スタイルで統一（線の太さ・影・角の丸み・光源は左上）。on/off の2状態があるものは同一形状で色だけ変える。
- 9slice 指定の画像は、四隅の装飾を保ち、四辺の中央に伸ばしても破綻しない無地帯を持たせる。
- bg/ 以外はすべて透過PNG。背景を白で塗りつぶさない。縁に白いフリンジを残さない。
- bg/ は不透明な全面背景（四角い画面をすみずみまで埋める）。周りが透明な切り抜きイラストにしない。
- scrim（グラデーション）と影は、それ単体の画像にする。ボタンやアイコンを一緒に描き込まない。
- 撮影画面（`camera/`）はライブ映像の上に重なるため、明るい映像でも暗い映像でも見えるよう半透明の暗い地＋白アイコンを基本にする。共有カード（`share/`）は枠と装飾だけを作り、写真・文字の差し込み領域を manifest に記録する。
- 実在の企業・キャラクター・ブランドのロゴは使わない。国旗と消印は一般的な意匠に留める。

## 作業手順
1. `git switch codex/ui-assets`
2. `ASSET_LIST.md` の カテゴリ順 に、まず **スタイル確定用の6枚**（`button/primary-orange.png`, `panel/card-cream.png`, `tabbar/home-on.png`, `icon/coin-paw.png`, `badge/rarity-rare.png`, `brand/logo-nekomobby.png`）を作り、参照画像と見比べて質感を決める。以降はその6枚を基準に全アセットを統一する。
3. カテゴリごとに生成し、`app/assets/ui/<カテゴリ>/` に保存。1カテゴリ終えるごとにコミット（例: `Add ui assets: button`）。
4. 生成後、サイズがリストと一致するか、透過になっているか、白フチがないかを確認。外れたものは作り直す。
5. `app/assets/ui/manifest.json` と `app/assets/ui/provenance/prompts-<カテゴリ>.md` を作る（形式は `ASSET_LIST.md` 末尾）。
6. 仕上げに、`docs/ui-reference` の4画面を意識した確認用の合成プレビュー `app/assets/ui/previews/contact-sheet.png` を1枚作る（全アセットの一覧画像）。

## やらないこと
- `app/src`, `App.tsx`, `package.json` などコードの変更。
- 既存の `assets/cat-mobbies/` の削除・上書き。
- 参照画像のスクリーンショットをそのまま切り出して使うこと（必ず新規に生成する。参照画像内の猫の写真・風景は構図の参考にとどめる）。
- `main` への直接コミット。

## 完了報告
作成枚数、リストに対する不足、作り直した枚数、気になった点を `app/assets/ui/README.md` にまとめる。
