## 共通ルール

- built-in image_gen を使い、既存素材と**同じ質感・縁取り・光源（左上）**にそろえる。写真のような質感・レンズのボケ・強い陰影は禁止。
- **文字は画像に焼き込まない**（数字・曜日・ラベルはアプリ側が描く）。例外は「brand/」の見出し・ロゴだけ。
- 透過が必要なものは透過PNG（白フチ・ハロー禁止）。`bg/`・`opening/bg` など全面背景は不透明。
- 伸縮して使う画像（9slice）は、透明な外周余白を影の分（約8px以内）に収め、manifest に `slice: {top,right,bottom,left}` を最終PNGのpxで必ず記録する。
- 新規・変更の画像は `app/assets/ui/manifest.json`（寸法・SHA-256・slice・生成プロンプト）と `assets/ui-records/provenance/prompts-<カテゴリ>.md` に記録し、一覧と作り直し回数を `assets/ui-records/README.md` に追記する。
- 寸法・透過・白フチなしを全件確認し、並べた確認画像を `assets/ui-records/previews/` に保存する。

## A. アプリ名の変更（【最優先】）

アプリ名は **「ねこモビー」ではなく「にゃこモビー」**（ひらがな「にゃこ」＋カタカナ「モビー」）。画像の中に名前が入っているものを、**同じファイル名・同じ寸法・同じ質感（こげ茶＋オレンジ、肉球ワンポイント）で描き直して上書き**する。

- 必須：`brand/logo-nekomobby.png`（760×240。ファイル名は変えない）、`brand/splash.png`（1179×2556、不透明、クリーム地の中央にロゴ）、`share/watermark.png`（360×120、半透明）。
- **全 PNG を開いて確認**し、「ねこモビー」「猫モビー」「ネコモビー」の文字が入っているものを探す（`share/discovery-card*.png`、`share/travel-card*.png`、`share/video-intro.png`、`share/video-outro.png`、`brand/title-*.png` などが怪しい）。見つかったものは同様に描き直す。見つけた一覧を `assets/ui-records/README.md` に書く。
- 注意：**キャラクターの種類名としての「猫モビー」は変えない**（アプリ名だけを変える）。画像内の文字がキャラの種類名なのかアプリ名なのか迷うものは、触らずに報告に書く。
- 文字は「にゃ」の小さい「ゃ」と「モビー」の長音「ー」が崩れないこと。何度か作り直して、読み間違いのない出来にする。

## B. 下部ナビバー → 各ボタンが独立した単一ボタン

今は `tabbar/bg.png`（横いっぱいの1枚のバー）の上に4つのアイコンを載せている。これを、**バーを廃止して、4つのボタンがそれぞれ独立して画面下に浮かぶ**形にしたい。ボタンとボタンの間はつながらず、背景（部屋）が見える。

新規フォルダ `app/assets/ui/navbtn/` に、**文字なし・アイコン入りの単体ボタン**を作る。

| ファイル | サイズ | 内容 |
|---|---|---|
| `navbtn/home-off.png` / `home-on.png` | 各 240×240 | ホーム（家） |
| `navbtn/deai-off.png` / `deai-on.png` | 各 240×240 | 出会い（猫の顔） |
| `navbtn/zukan-off.png` / `zukan-on.png` | 各 240×240 | 図鑑（開いた本） |
| `navbtn/world-off.png` / `world-on.png` | 各 240×240 | 世界（地球） |
| `navbtn/glow.png` | 320×320 | 選択中のボタンの後ろに敷く、オレンジのやわらかい光（透過） |

- 形：**ぷっくりした丸みの四角（スクワークル）または丸**で、4つとも同じ形・同じ大きさ。1つだけで見ても「押せるボタン」だとわかる立体感（上辺のハイライト、縁取り、下に落ち影）。ボタン外周と落ち影は **画像の中に収める**（余白は影の分だけ）。
- off：クリーム〜生成りの地、茶グレーのアイコン。on：オレンジの地（やや浮いて見える）、白〜クリームのアイコン。off と on で**大きさ・位置は同じ**（アプリ側で拡大・上下に動かす）。
- アイコンは既存の `tabbar/*-on|off.png` と同じ題材を、ボタンに収まる大きさで描き直す（既存の `tabbar/*` は削除しない）。
- 部屋の背景や木の床の上に置いても、**ボタンの輪郭が埋もれない**こと（縁取りと影を確実に）。
- あわせて、ボタン列の背後に敷いていた `tabbar/bg.png` は使わなくなるので、**ボタンどうしを結ぶ装飾は描かない**。

## C. ホーム背景（`bg/room-home.png`）の修正

> 下の2枚のカードの裏に背景が足りず余白ができる問題は、別紙 `docs/codex/UI_V3_HOME_BG_PROMPT.md`（全画面版 `bg/room-home-full.png`）で扱う。C と合わせて作る。

ナビがバーでなくなり、**ホーム画面の下端に4つの独立ボタンが浮かぶ**ため、背景を調整する。同じ名前・同じ寸法（1179×1900、不透明）で上書きする。**今の部屋のタッチ・色味・家具の配置は保つ。**

- 現状の見直し点：
  1. **ラグが左右の端に接して切れている** → ラグ全体が画面内に収まるよう小さくする（左右に少し床が見える）。
  2. **床が下に長く、板目の線が強く走っている**（縦 70〜100%）→ 下の方の板目は**ほぼ消して、なだらかなオレンジの床**にする。浮かぶボタンの輪郭が読めるように。
  3. 縦 85〜100% は、4つのボタンが浮かぶ帯。**何も置かず、明るさの差・模様をなくす**（低コントラスト）。左右の端にも家具や植物を置かない。
  4. **縦 50〜75% の床とラグの中央は何も置かない**（猫が立つ）。右下 85% 付近（カメラボタン）も空ける。
  5. 上 0〜12% はヘッダーが重なる → なだらかにする（カーテンレールや植物の葉が近すぎるなら少し下げる）。
- 加えて、右上（縦 12〜30%、右寄り）に**壁の空いた余白**を作る（今はキャットタワーと棚がある）。ここに新しいボタン（ログイン記録）を重ねる予定なので、**細かい物を避け、単純な壁**にしておく。今ある棚は残してよいが、右端の植物やタワーの先端がこの余白にかからないようにする。
- 描き終えたら、旧版と並べた比較画像を `assets/ui-records/previews/home-compare.png` に保存。
