# 新規 猫モビー 生成リスト

出典: `docs/appearance-catalog.md`（出現条件・名前・由来の企画台帳）。
ここでは台帳の名前付き猫を **生成バッチ** に分け、ID・名前・ビジュアル案を決めている。

- 名前は仮称。台帳で重複・別名になっていたものは、下の「名前の統一案」で仮に分けた（企画側で確定したら `name` だけ差し替える）。
- 出現条件は参考情報。画像の見た目には条件のテーマ（数字・天気・時間など）を **小さな小物か表情** で反映する。
- ビジュアル案の「毛」は体の基本色。目の色は **生体の目（画面左）** の虹彩色。もう片目はカメラレンズ（画面右）で固定。
