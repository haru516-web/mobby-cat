## 0. 作業の始め方（worktree）

リポジトリ: `haru516-web/mobby-cat`（GitHub）。すでに手元にあれば、そのルートで次を実行する。なければ `git clone https://github.com/haru516-web/mobby-cat.git` してから。

```bash
git fetch origin
git worktree add .worktrees/ui-fixes codex/ui-fixes     # ブランチは作成済み。無ければ origin/codex/ui-fixes から
echo ".worktrees/" >> .git/info/exclude                  # worktree フォルダを git の管理対象外にする
cd .worktrees/ui-fixes
git branch --show-current                                # codex/ui-fixes であることを確認
```

- **以降の作業はすべて `.worktrees/ui-fixes` の中だけ**で行う。元のフォルダ（ルート）と他のブランチは触らない。ブランチも切り替えない。
- グループごとにコミットし、**そのたびに `git push origin codex/ui-fixes`** する（途中で止まっても成果が残るように）。

## 2. 【最優先】写真のようになっている背景を、絵のタッチで描き直す

### 何が問題か
今の背景は **実写の写真のよう**（被写界深度のボケ、床の木目の反射、布の繊維、レンズのような光）になっている。ボタンやカードなど他の画像は「ぷっくりしたやさしい絵」なので、背景だけが浮いて見える。**同じファイル名・同じサイズで、絵として描き直す。**

### 目指す絵のタッチ（必ず守る）
- `docs/ui-reference` の背景と同じ、**丸くやわらかい形の、かわいいゲーム背景イラスト**。絵本・ゲームUIの背景のイメージ。
- 形は単純化する。細かすぎる質感（木目の1本1本、布の繊維、葉脈）は描かない。塗りは「平らな色＋やわらかいグラデーション＋うすいハイライト」。
- 輪郭はやわらかく、色数は絞る。暖かい生成り・ベージュ・やさしい緑・淡いオレンジが基調。
- **禁止：** 写真のような質感、レンズのボケ（被写界深度）、レンズフレア、強い陰影、コントラストの強い暗部、実在の店名・ブランド名。**ひと目で「絵」だとわかること。**
- 画像の中に **猫・人は描かない**。**文字は入れない**（世界のヒーローの道しるべの英字だけ例外：JAPAN / FRANCE / KENYA / KOREA）。
- 背景（bg/）は **不透明で、四角を全面埋める**。透過にしない。

### 空けておく場所（アプリは画像の上に部品を重ねる）
- **`bg/room-home`（縦を100%として）**：上 0〜12% はヘッダー、下 85〜100% はナビバーとカードが重なる → ここは細かい物を置かず、なだらかにする。**縦 50〜75% の床の中央は何も置かない**（猫が立つ）。右下 85% 付近（カメラボタン）も空ける。
- **`bg/room-deai`**：上 0〜30% は見出し画像が重なる → 明るく模様を少なく。30〜62% は猫3匹が重なる → **低コントラストの単純な壁と床**。

- **`bg/screen-*`**：中央〜下はカードの文字が載るので特に淡くする。

### 見比べて直す
- 描き終えたら、`docs/ui-reference/01-home.webp` `03-deai.webp` `04-world.webp` の背景と並べて、**絵のタッチ・色味・密度が揃っているか**を確認する。写真っぽさが残るものは作り直す。
- 並べた確認画像を `assets/ui-records/previews/regen-compare.png`（作り直し前後の比較）として保存する。

## 3. 【差し替え】`tabbar/bg.png` の作り直し

- 現状: 1179×300。上の角だけでなく**下の角も丸く、下辺にも茶色の縁取りがある**。画面の最下部に置くと、下の角の外側に背景（クリーム色）が見えて、バーの後ろに白っぽい帯があるように見える。
- 作るもの: 同じ質感・同じ色・同じ上辺のハイライトで、**下辺が画面の下端まで突き抜ける形**にする。
  - 上の左右の角は今と同じ大きな角丸（縁取りあり）。
  - 下の角は丸めない。下辺の縁取りも描かない（左右の縁取りは下端まで直線で伸ばして切る）。下端の落ち影も描かない。
  - 上辺の外側に、上向きの低コントラストな落ち影を少し足してよい。
- サイズ: 1179×300、透過PNG（角丸の外側と影だけ透過）。
- 9slice: `{ t: 90, r: 90, b: 0, l: 90 }`（下は伸ばさず固定キャップなし）。manifest に反映。
- 同じ形を使う `tabbar/active-glow`・`underline` は変更しない。

## 6. 進め方と完了条件

1. 最初に **`bg/room-home.png` だけ** を描き直し、参考画像と並べて絵のタッチを確定する（ずれていたら直してから残りへ）。
2. 優先順（2 → 3 → 4 → 5）に、グループごとにコミットして `git push origin codex/ui-fixes`。
3. 寸法・透過（bg/ は不透明、それ以外は透過）・白フチなしを全件確認する。
4. `app/assets/ui/manifest.json`（寸法・SHA-256・slice・生成プロンプト）と `assets/ui-records/provenance/prompts-<カテゴリ>.md` を更新する。
5. 変更・追加した画像の一覧と、作り直しの回数を `assets/ui-records/README.md` に追記する。
6. 画像の読み込み（`app/src/ui/uiAssets.ts`）は、こちらで `tools/build-ui-registry.ps1` を実行して更新する。**新規ファイル名は上の表のとおり**にする。コードは触らない。

## 7. やらないこと

- コード（`app/src`、`App.tsx`、`package.json`）の変更。
- 猫モビーの画像（`assets/cat-mobbies/**`、`app/assets/cats/**`）の変更。これは別の依頼②の担当。
- `main` や他のブランチへのコミット。ルートのフォルダでの作業。
