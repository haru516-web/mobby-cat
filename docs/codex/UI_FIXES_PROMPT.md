## 1. `tabbar/bg.png` の作り直し（差し替え・最優先）

- 現状: 1179×300。上の角だけでなく**下の角も丸く、下辺にも茶色の縁取りがある**。そのため画面の最下部に置くと、下の角の外側に背景（クリーム色）が見えて、バーの後ろに白っぽい帯があるように見える。
- 作るもの: 同じ質感・同じ色・同じ上辺のハイライトで、**下辺が画面の下端まで突き抜ける形**にする。
  - 上の左右の角は今と同じ大きな角丸（縁取りあり）。
  - 下の角は丸めない。下辺の縁取りも描かない（左右の縁取りは下端まで直線で伸ばして切る）。下端の落ち影も描かない。
  - 上辺の外側に、上向きの低コントラストな落ち影を少し足してよい。
- サイズ: 1179×300、透過PNG（角丸の外側と影だけ透過）。
- 9slice: `{ t: 90, r: 90, b: 0, l: 90 }`（下は伸ばさず固定キャップなし）。manifest に反映。
- 同じ形を使う `tabbar/active-glow`・`underline` は変更しない。

## 2. 空状態のイラスト（新規2枚）

お知らせ・出会い履歴・これからの各一覧が空のときに、今は文字だけが出ている。やさしい空状態の絵を足す。

| ファイル | サイズ | 内容 |
|---|---|---|
| `illust/empty-notice.png` | 600×450 | 丸くなって眠る猫モビーと、枕元の小さな封筒。静か・あたたかい雰囲気。 |
| `illust/empty-history.png` | 600×450 | 空のポラロイド枠を前足でちょこんと押さえる猫モビー。 |

- 透過PNG。背景は塗らない。下に小さな落ち影を付ける。
- 猫モビーの識別要素（片目がカメラレンズ、胸元の十字キー、丸ボタン2つ）を入れる。既存の `assets/cat-mobbies/characters/*.png` から1匹選んで姿勢だけ変えてよい（元ファイルは上書きしない）。
- 文字は入れない。
