## 検品メモ（Codex が使う）
- 100種の ID が重複していないこと。既存（上の一覧、および `assets/cat-mobbies/new/manifest.json` の100匹）と **名前・IDが衝突しない**こと。
- 同じ毛色の猫が並ばないよう、**サムネイル（512px）で見分けがつくか**を確認する。色が近い組（例：british-black / russian-black / kuro-neko）は、**体型・耳・顔つき・毛の長さ・目の色**で差をはっきり出す。
