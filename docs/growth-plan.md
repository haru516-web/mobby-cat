# ねこモビー 公開に向けたブラッシュアップ計画

目標：**世界中の猫好きに広まり、毎日開かれ、課金する人も多く、愛されるアプリ**にする。

進め方：ユーザーの行動を「興味 → インストール → 初日 → 継続 → 課金 → 人に教える」に分け、それぞれ「なぜそうするのか」を問い、足りないものをタスクにする。タスクごとに成功している類似例（アナロジー）を探し、見つかればそれを手本に作る。見つからなければタスクをさらに細かくして探し直す。

状態の凡例：✅ 今回実装 / 🔜 次に実装（技術的に可能・優先度高） / 🧱 サーバーや外部契約が必要

---

## 1. なぜ興味を持つのか（興味・インストール）

| 問い | 答え（このアプリの約束） | アナロジー |
|---|---|---|
| 何が新しい？ | **自分の生活（歩数・電池・暦・月）がそのまま猫との出会いになる**。ゲームを「遊ぶ」のではなく、暮らすだけで猫が来る | ねこあつめ（放置で猫が来る）× ポケモンGO（現実の行動がゲームになる） |
| なぜ今入れる？ | 「今日は13日の金曜日だから○○が出る」など、**今日しか会えない猫**がいる | Wordle（今日の1問）、ポケモンGOの期間限定イベント |
| 何が可愛い？ | 片目がカメラ、胸にゲームボタンという一目でわかる**キャラクターの型**と、136種の個性 | たまごっち・すみっコぐらし（型が決まったキャラの大量バリエーション） |

### タスク
- ✅ **初回起動で相棒を選ぶ**：3匹から1匹を選んでその場で家族にし、「毎日20時に出会いが来る」ことを体験で教える。（アナロジー：ポケモンの御三家選び。最初の選択が愛着になり、SNSで「どれにした？」が生まれる）
- ✅ **相棒を選んだあとのチュートリアル**：画面を暗くして説明する場所だけ明るく残す9段（お迎え券・ベル・猫部屋・今日の出会い・候補・追加お迎え・図鑑・世界）。スキップ可、設定の「使い方」から見返せる。（アナロジー：mobidou のアプリ内ツアー。ポケモンGOの最初の案内）
- 🔜 **App Store のスクリーンショット・紹介文**：「歩くと猫が来る」「満月の夜だけの猫」など条件そのものを見せる。（アナロジー：ねこあつめのストア画像は「庭に猫が来る」1点に絞っている）
- 🧱 **多言語化（英語→韓国語・中国語）**：世界の猫好きに届けるには必須。文字入り画像（brand/）は言語別に作り直しが必要。（アナロジー：ねこあつめは英語版で海外に広がった）

## 2. なぜ初日に楽しいのか（オンボーディング）

| 問い | 答え | アナロジー |
|---|---|---|
| 最初の5分で何が起きる？ | 相棒を選ぶ → 猫部屋に来る → 今日の出会いで2匹目を選ぶ → 図鑑に2/136が埋まる | ポケモン：最初の1匹 → 図鑑が埋まり始める快感 |
| 次に何を待てばいい？ | 次の20時までのカウントダウンと、**これから会える猫の予告** | どうぶつの森のイベントカレンダー |

### タスク
- ✅ 相棒選び（上記）
- ✅ **「これから会えるかも」カレンダー**：暦・月で決まる条件猫を、今後30日分シルエットで予告する。（アナロジー：あつ森の「来週は釣り大会」、ポケモンGOのイベント予告。待つ理由がアプリを開く理由になる）

## 3. なぜ毎日開くのか（継続）

| 問い | 答え | アナロジー |
|---|---|---|
| 毎日の理由 | **20時の出会い**（1日1回の儀式）。通知は20時に1回だけ | Wordle（1日1問）、BeReal（毎日の通知1回） |
| 開かなかった日はどうなる？ | 翌日まで受け取れる。休んでも「ひさしぶりモビー」など**休んだことが楽しみになる** | Duolingoの連続記録は休むと失うが、こちらは**罰ではなく再会**（企画書の方針） |
| 開いたら何をする？ | 猫部屋で猫をなでる、図鑑を眺める、明日の予告を見る | ねこあつめ（庭を眺める）、たまごっち（世話） |
| 取り逃しは？ | **出会い履歴**で、迎えなかった子・会えた条件を振り返れる | ガチャの排出履歴、Spotifyの再生履歴 |

### タスク
- ✅ **出会い履歴（ベルから開くお知らせ）**：過去の出会い、迎えた子、迎えなかった子を一覧。ベルを本来の「お知らせ」に。
- ✅ **猫部屋のふれあい**：猫をなでるとぴょんと跳ねてハートが出る。なでた回数を記録（企画書の世界目標「なで100万回」の土台）。（アナロジー：たまごっち、ねこあつめのタップ反応）
- ✅ **7日連続でお迎え券を1枚プレゼント**（休んでも減らない）。（アナロジー：ねこあつめの「あいことば」で毎日にぼし。小さく確実な見返り）
- 🔜 **通知文を毎日変える**：その日の条件猫がいるときは「今日は満月。まんげつモビーが来ています」。（アナロジー：Duolingoの通知は文面のバリエーションで開封率を上げている）
- 🔜 ホーム画面ウィジェット（今日の出会いまでのカウントダウン）。dev build が必要

## 4. なぜ課金するのか

| 問い | 答え | アナロジー |
|---|---|---|
| 何に払う？ | **今日出会った「欲しい子」を確実に迎える**（お迎え券）。結果にランダム性がない | ねこあつめのゴールド煮干し（欲しいグッズを確実に買う） |
| 何を増やす？ | **出会いの数**（またたび）。迎えられるのは無料1匹のまま | ポケモンGOの「ふかそうち」「おこう」 |
| 定期的に払う理由 | **またたびパス**：毎日の候補が増え、月にお迎え券も届く | バトルパス、Apple Arcade型の月額 |
| 安心して払える？ | 出現確率を購入前に表示、購入の復元、期限の明示 | App Store の確率表示ガイドライン（3.1.1） |

### タスク
- ✅ **出現確率の表示**：レア度ごとの確率をショップで開示（ランダム要素のある「またたび」の購入前に必要）。
- ✅ **またたびパス（テスト）**：加入中は毎日候補+3、月3枚のお迎え券。解約後の扱いを明記。
- ✅ **購入の復元ボタン**（テスト版では案内のみ）。
- 🧱 **本物のアプリ内課金**：StoreKit（RevenueCat等）の組み込みとレシート検証。dev build とサーバーが必要。
- 🔜 開発用ボタン（日付を進める等）は**開発ビルドでだけ表示**する ✅（今回 `__DEV__` で隠した）

## 5. なぜ人に教えたくなるのか（拡散）

| 問い | 答え | アナロジー |
|---|---|---|
| 何を見せたい？ | 「満月の夜にだけ来る子に会えた」**発見の証拠** | ポケモンGOの色違いスクショ、Wordleの結果グリッド |
| どう見せる？ | **発見カード**と**猫と撮った写真**をワンタップで共有 | Spotify Wrapped（共有前提のカード）、Snapchatレンズ |
| 教える理由 | 条件は全員共通なので、**攻略情報に価値がある**（「歩数2,222歩で出るよ」） | Wordleのヒント共有、どうぶつの森のカブ価情報 |

### タスク
- ✅ **発見カードの共有**：猫を迎えたら、名前・出会った日・条件つきのカード画像を作って共有。
- ✅ **撮影（カメラ合成）**：カメラの映像に猫を置いて、ドラッグで移動・ピンチで拡大・回転して撮影し、保存・共有。（企画書 8.1。アナロジー：ポケモンGOのARスナップショット）
- ✅ 共有文に `#ねこモビー` と条件のヒントを入れる（攻略投稿を促す）。
- 🧱 旅猫・世界ミッション・国数達成：サーバー必須。今は「サンプル表示」と明記した見本を表示 ✅（旅の記録・ニュース一覧を開けるようにした）

## 7. 公開前の品質

- ✅ **レスポンシブ確認**：iPhone SE（320/375）〜 Pro Max（430）、iPad（768以上はスマホ幅で中央表示）で崩れないか。
- ✅ 画像ボタンに読み上げラベル（VoiceOver）。
- 🔜 プライバシーポリシー・利用規約のページ（App Store 審査で必須）。誕生日・歩数は端末内のみ保存と明記。
- 🔜 iOS 実機（Expo Go）での動作確認：歩数・電池・通知・カメラ。
- 🧱 アカウント／機種変更時の引き継ぎ（サーバー必須）。

### レスポンシブ確認の結果（Web・iPhone幅で表示）
| 幅 | 結果 |
|---|---|
| 320（SE 第1世代） | 「くわしく見る」の折り返し、図鑑の所持数の欠け、ヘッダーの窮屈さを修正 |
| 375（SE 第2・3世代） | ピルのラベルが途切れるため、390未満ではラベルを省略 |
| 393 / 430（標準・Pro Max） | 問題なし |
| 768以上（iPad） | スマホ幅（430）で中央表示。問題なし |

## 8. 残っている改善点（優先順）

1. 🔜 **iPhone 実機（Expo Go）での確認**：歩数・電池・通知・カメラ・保存・共有。Web では確認できない。
2. 🔜 **プライバシーポリシーと利用規約のページ**（審査必須）。アプリ内の説明は追加済み。
3. 🧱 **本物のアプリ内課金**（StoreKit / RevenueCat、レシート検証、購入の復元）。
4. 🔜 **通知文を日ごとに変える**：その日の条件猫を知らせる。毎日の通知をアプリ起動時に組み直す方式にする。
5. 🧱 **多言語化**：英語版の文字入り画像（brand/）を Codex に依頼し、文言を辞書化する。
6. 🔜 **図鑑から発見カードを共有**（今は迎えた直後のみ）。
7. 🔜 **天気の条件**（9匹が「準備中」）：Open-Meteo など無料の天気 API と、地域の選択。
8. 🧱 **旅猫・世界ミッション・国数達成**：サーバーと不正対策。今はサンプル表示。
9. 🔜 **App Store 用スクリーンショットと紹介文**。
10. 🔜 Web の Alert は動かないため、確認ダイアログを画像のモーダルに置き換える（iOS では問題なし）。

### 2026-10-25 に決まって、これから実装するもの
詳しくは `game-design.md` の「16. 決定事項」。

- 🔜 **相棒選び**：ノーマルモビーから均等な抽選で3種を出す。再抽選は最大3回（残り回数を表示）。
- 🔜 **条件猫が3匹を超えたとき**：均等にシャッフルして3匹を見せる。通常の抽選もレア度の重みをやめて均等にする。ショップの出現確率の表示を直す。
- 🔜 **またたびパスの説明**：「加入者は候補が3匹から6匹になる」と明記する。
- 🔜 **なでる50回の特別なモビー**：なでる回数の節目で無条件に渡す。
- 🔜 **発見カード**：複合条件だけ片方を伏せたヒントにする。
- 🔜 **ホーム画面**：ユーザーが選んだ猫を置く。背景は置き場所を空けた絵にする（Codex の `codex/ui-fixes` の指示書に座標を足す）。
- 🧱 **Appleサインイン（任意連携）**：必須にはしない。連携を勧める案内を、チュートリアル後・最初の課金前・設定画面に出す。サーバーは mobidou と同じ構成で別に作る。
