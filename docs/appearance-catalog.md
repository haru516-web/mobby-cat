# にゃこモビー 出現条件・名前・由来 一覧

- 作成日：2026-10-25
- 対象：にゃこモビー iOSコレクションゲーム
- 文書の位置付け：これまでの企画で登場した**名前付きのにゃこモビー案と出現条件**を集約した企画用カタログ。**猫名・条件の多くは仮称／未確定**。
- 原則：特殊な出現条件は全ユーザー共通。毎日20:00（利用者の現地時刻を想定）の候補抽出に反映する。ただし、例外として世界共通報酬は直接配布、世界唯一の旅猫は「訪問」扱いとし、一般猫と区別する。
- 用語：「出現」＝その日の**出会い候補になる**こと。「獲得」＝候補からお迎えすること。出現条件達成時に確実に候補へ含めるか、複数条件が重なったときの超過枠の処理は未決定。
- 一部、会話中で同一条件に別名が挙がっている。両方記録し、後で統一する。

## 10. 20時の出会いに統合する際の判定原則（未確定事項を明記）

1. **全ユーザー共通の条件表**を持つ（例：13日の金曜日なら、誰にとっても「のろわれモビー」の条件）。ただし実際にその条件を満たしたかどうかは各ユーザーの生活・地域による。
2. 原則、**毎日20時に3匹の出会い候補**を確定する。事前に使った消費型**またたび**や**またたびパス**で最大6匹程度に増やす案。
3. 候補から**1匹は無料**で迎えられ、残りは**お迎え券**で追加獲得。候補のレア度でお迎え券の価格を変えない案が有力。
4. 条件に一致する猫が4匹以上になった場合の**候補枠の優先順位・取り逃し救済・複数の条件猫を確定表示する方式**は未決定。攻略情報を無意味にしないため、重要な特殊条件猫の出現保証が望ましい。
5. 国数到達・世界協力達成の記念猫は、20時の3択とは別に**全ユーザーへ無料配布**する案を優先。
6. 世界唯一の旅猫は**所有する猫**ではなく**一時的に訪問する猫**として扱う。写真撮影や旅行記への記録を残す。
7. 歩数・バッテリー・時間帯・天気・暦について、どの時点のデータを用いるか（当日20時まで／前日／当日締め）を仕様化する。
8. 低頻度の特殊日・天文現象に遭遇できなかった場合の救済は、無課金の再入手機会と有料の確定救済を両立させる。
9. 名前の重複（にゃんにゃん、ぞろめ、はんぶん、マラソン、せかい、王様など）は**猫種IDを一意にする前に解消**する。
10. 「追加の候補を購入する」ようなランダム型有料商品を提供する場合は、Appleの適用される確率開示などの要件を確認する。
