# ノーマル条件の見直し（2026-10-31）

対象は画面上ノーマルの実在猫169匹。全169匹を変更し、旧24匹の「季節×曜日×電池」の割り当てを廃止。レア・でんせつ・世界・旅猫のレシピは変更していない（旧版の非ノーマル全レシピの指紋をテストで比較）。抽選・落選優遇・保存済みの日の候補と理由はそのまま。

## 条件の設計

- `app/src/core/normalRecipes.ts` に猫IDごとの3〜4条件を明記。完全一致0組。カタログ順の変更や起動のたびに条件を作り直さない。14の組み合わせ方を用意し、季節・曜日・電池だけの救済用セットは置かない。設計用スクリプトは `tools/design-normal-recipes.mjs`。テーマの分配はID順で行った固定表で、猫種の性格を調査して個別に割り当てたものではない。
- 歩数（少ない日・中間の範囲も含む）、天気、季節、曜日、朝昼夕夜、電池と充電、月齢、連続起動の段階、3日以上ぶりの起動を使う。
- お気に入り1/3/6種、ノーマル所持5/15/30種、レア・でんせつ所持1/3種、全所持3/10/20種、なでた累計5/30/100回、ホームの手動設定、誕生日設定も使う。所持数は匹数ではなく種類数。世界・旅猫はレア所持数に含めない。
- 設定済み・累計・所持の条件は、その日の材料と組み合わせる。これらを使う組み合わせの多くは4条件にして、進行後に全員が毎日成立することを抑える。なでる回数は「今日」ではなく保存済みの累計。ホーム設定は手動の配置が保存されている状態（入れ替えた日という意味ではない）。
- ノーマルの時間帯・電池は、出会いの1日（前日20時〜当日20時、既存の観測方式）の最初の記録を使用。繰り返し起動して全時間帯・電池帯を同時達成することを抑える。充電は期間中に観測したか。レアの判定方式は変更しない。記録がなければ、その条件は不成立。
- Apple連携を猫の条件にはしていない。任意連携を収集の必須条件にしないため。現在取得不能の限定所持数も使わない。追加の権限・通信・個人情報の保存は不要。旧保存に新しい必須項目は加えない。
