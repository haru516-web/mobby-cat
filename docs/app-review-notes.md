# App Review 用メモ（App Store Connect の「審査メモ」に貼る文面の下書き）

提出前に、運営者が内容を確かめて貼る。Apple の質問票の回答は、運営者が決める（`app-store-privacy.md`）。

## 日本語の下書き（英語版は提出時に訳す）

**アカウントについて**

- ログインは不要です。購入したときに、匿名のアカウント（ランダムな番号）が作られます。Apple でのサインインは任意です。
- 購入の復元：ショップの「購入を復元」から行えます。加入中のまたたびパスは、この操作だけで戻せます。購入済みのお迎え券・またたびを別の端末へ引き継ぐには、前の端末の「設定 → アカウント」で発行した引継ぎコードを入力します。
- アカウントの削除：「設定 → アカウント → アカウントを削除する」から行えます。

**出会いの仕組み（アプリ内「ショップ → 出会いの仕組み」と同じ内容）**

- 毎晩20時に、その日の出会いの条件がすべてそろった猫が候補に並びます。条件をすべて満たしたら、その日の候補に必ず出ます。
- 条件を満たした猫を候補から抽選で外すことはありません。候補は届いた時点ですべて見えます。同じ日・同じ状態なら顔ぶれも同じです。
- ノーマルの猫は、歩数・天気・起動の時間帯・電池・曜日・月の状態・所持や設定など、猫ごとに決まった条件があります。条件を満たした猫だけが候補に並びます。
- 条件を満たす猫がいない日には、日付で決まる軽い条件を持つノーマルが1匹候補に加わります。候補が0匹の日はありません。
- その日、候補から1匹を無料で迎えられます。「お迎え券」を使うと、候補からもう1匹を選んで迎えられます。条件を飛ばして猫を迎えることはできません。
- またたびとまたたびパスは、現在ショップで新規購入を一時停止し、内容を見直しています。購入済みの残高や加入中の契約は記録に残ります。購入済み商品の復元・引き継ぎは引き続き利用できます。

**権限の使い道**

- モーションとフィットネス：その日の歩数を出会いの条件にするために読み取ります（端末の中だけで使います）。
- 位置情報（使用中のみ・任意）：その日の天気を調べるために、小数第1位に丸めた位置を天気予報サービス（MET Norway）へ1日1回送ります。位置情報を許可しなくても、毎日ノーマル1匹の候補があります。
- カメラ：猫と一緒に写真を撮る機能に使います。
- 通知（任意）：毎日20時の出会いのお知らせを端末の中で予約します。

**確かめ方**

- ショップは、画面上のヘッダーのお迎え券・またたびの所持数を押すと開きます。初めて購入するときは、年齢の区分を選ぶ画面が出ます（毎月の購入上限のため）。またたびとまたたびパスは、現在「準備中」と表示され、新規購入できません。
- 「出会いの仕組み」から、候補に出る条件と毎日の候補の決まり方を確認できます。
- 設定の開発用の項目は、公開版では表示されません。サンドボックスのアカウントで、お迎え券の購入と購入の復元を確かめられます。
- 初めて起動した日は、20時になるまで最初の出会いが届きません（待ち画面に案内が出ます）。ホームでは、猫をなでる、さつえい、図鑑が使えます。

条件一覧と出現数のシミュレーションは [猫ごとの条件表](cat-conditions.md) と [ノーマル条件の見直し](normal-conditions-redesign.md) を参照してください。
