# App Review 用メモ（App Store Connect の「審査メモ」に貼る文面の下書き）

提出前に、運営者が内容を確かめて貼る。Apple の質問票の回答は、運営者が決める（`app-store-privacy.md`）。

## 日本語の下書き（英語版は提出時に訳す）

**アカウントについて**
- ログインは不要です。購入したときに、匿名のアカウント（ランダムな番号）が作られます。Apple でのサインインは任意です。
- 購入の復元：ショップの「購入を復元」から行えます。加入中のまたたびパスは、この操作だけで戻せます。匿名で購入したお迎え券・またたびを別の端末へ引き継ぐには、前の端末の「設定 → アカウント」で発行した引継ぎコードを入力します。
- アカウントの削除：「設定 → アカウント → アカウントを削除する」から行えます。

**出会いの仕組みと確率（アプリ内「ショップ → 出会いの仕組み」と同じ内容）**
- 毎晩20時に、その日の出会いの条件がすべてそろった猫の中から、候補が決まります。
- そろった猫が6匹以下の日は、全員が候補になります。7匹以上の日は、同じ確率で6匹が選ばれます（たとえば10匹なら、どの猫も60%）。猫ごとの重みづけはありません。
- 候補は、届いた時点で決まっていて、購入では変わりません。ガチャのように、購入した瞬間に結果が決まることはありません。
- 候補は、ひらくまで中身（どの猫か）が見えません。ひらく候補は、利用者が選びます。ひらいた猫は、その日の候補の別々の猫で、はずれはありません。
- 無料で3匹までひらけます。「またたび」（消耗型）は、ひらける数を1匹ずつ増やします（最大6匹）。出る猫の確率は変わりません。「お迎え券」（消耗型）は、ひらいた猫の中から、迎える猫を選べる券です。「またたびパス」（自動更新サブスク）は、ひらける数を6匹までにします。
- 以上の説明は、購入の前に、ショップの画面で読めます。

**権限の使い道**
- モーションとフィットネス：その日の歩数を、出会いの条件にするために読み取ります（端末の中だけで使います）。
- 位置情報（使用中のみ・任意）：その日の天気を調べるために、小数第1位に丸めた位置を、天気予報サービス（MET Norway）へ1日1回送ります。
- カメラ：猫と一緒に写真を撮る機能に使います。
- 通知（任意）：毎日20時の出会いのお知らせ（端末の中で予約します）。

**確かめ方**
- ショップは、画面上のヘッダーのお迎え券・またたびの数を押すと開きます。初めての購入の前に、年齢の区分を選ぶ画面が出ます（毎月の購入上限のため）。
- 設定の開発用の項目は、公開版では表示されません。サンドボックスのアカウントで、購入と購入の復元を確かめられます。
- 初めて起動した日は、20時になるまで最初の出会いが届きません（待ち画面に案内が出ます）。ホームでは、猫をなでる、さつえい、図鑑が使えます。
