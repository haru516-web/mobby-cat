## 説明文

```
歩いた数、電池の残り、今日の天気、季節や曜日、時間帯。
いつもの暮らしに合わせて、その日だけの猫「にゃこモビー」と出会えるアプリです。

■ 毎日、条件がそろった猫と出会う
毎晩20時、その日の条件がそろった猫が、候補として届きます。ひらくまで誰が来たか分からない候補を、3匹までひらいて選べます。
その中から1匹を、無料で迎えられます。条件がそろわない日は、候補が少なくなります。
たくさん歩いた日、雨の日、朝に開いた日、誕生日。条件の合う日にしか会えない猫もいます。

■ コレクションを集める
迎えた猫は、コレクションに記録されます。
どんな日に会えるのか、条件を探すのも楽しみのひとつです。

■ 一緒に写真を撮る
カメラで、猫と一緒に写真を撮れます。撮った写真は、写真アプリへの保存や共有ができます。

■ もっと会いたい日は
・お迎え券：候補の中から、もう1匹を確実に迎えられます。
・またたび：条件がそろった猫が4匹以上いる日に、候補をもう1匹ひらけます（候補の数まで）。
・またたびパス（月額サブスクリプション）：加入中は、毎日6匹まで候補をひらけます（ふだんは3匹）。毎月お迎え券が8枚届きます。

無料でも、候補がいる日は1匹ずつ、猫を集められます。
お迎え券は、候補の中から迎える猫を選べる券です。候補は、毎晩20時に、条件を満たした猫の中から決まり、購入では変わりません。条件を満たしたレア・でんせつ・世界の猫は候補に残ります。ふだんの候補は6匹までで、レア以上だけで6匹を超える日は全員を残します。残りの枠はノーマルから選び、そのうち1枠は未所持の子を優先します。条件がそろっても候補から外れた子は、次に条件がそろった日の抽選で少し出やすくなります。外れた回数1回につき重みが0.5増え、最大11倍です。候補に入ると重みは戻ります。条件がそろわない日は選ばれません。またたびは、ひらける数を1匹ずつ増やすもので、ひらくまで中身は分かりません。ひらいた猫は、その日の候補の別々の猫で、はずれはなく、またたびで確率は変わりません。出会い画面には、ひらいた候補と非表示の子のレア度ごとの数を表示します。条件を満たした珍しい猫がまだひらかれていない日は、気配を知らせます。名前や条件は明かしません。しくみは、アプリのショップの「出会いの仕組み」で、購入の前に確認できます。

■ 引き継ぎ
Appleでサインインすると、機種変更しても、猫・コレクション・購入したアイテムを引き継げます。メールアドレスや名前は受け取りません。
サインインしない場合、迎えた猫と記録は端末の中だけにあり、機種変更やアプリの削除で消えます。サインインせずに購入した場合、お迎え券・またたびは引継ぎコードで、加入中のまたたびパスは「購入を復元」で、新しい端末へ移せます（猫と記録は移せません）。

■ 使う情報について
・歩数：その日の出会いを決めるために、端末の中だけで読み取ります。
・位置情報（任意）：その日の天気を調べるために、おおまかな位置だけを使います。許可しなくても遊べます。
・カメラ：猫と写真を撮るときだけ使います。
・毎日20時のお知らせは、設定でいつでも切れます。
広告の表示やアクセス解析はありません。

■ またたびパス（自動更新サブスクリプション）について
・料金：月額 1,500円（税込）。App Storeに表示される価格が適用されます。
・購入の確定時に、Apple Accountに請求されます。
・期間が終わる24時間前までに解約しない限り、1か月ごとに自動で更新され、Apple Accountに請求されます。
・解約は、iPhoneの「設定」→ 上部の名前 →「サブスクリプション」から、いつでもできます。
・解約しても、迎えた猫は残ります。

プライバシーポリシー：https://nyakomobby-server.mobidou.workers.dev/privacy
利用規約：Apple標準の使用許諾契約（EULA）：https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
```

## 公開前の確認

- 説明文の「1,500円」は、App Store Connect で設定した価格と一致させる。
- 説明文の条件の例は、`docs/cat-conditions.md`（歩数・天気・電池・時間帯・季節・曜日）と誕生日の機能に合わせてある。条件を増減したら見直す。
- 利用規約を独自のページにしたら、説明文の末尾の行と `TERMS_URL` を差し替える。
- 審査用メモの操作名（「ショップ」「購入を復元」「アカウント」）が、実機の表記と一致するか、実機で確認する。


ノーマルの出会い条件は、天気・歩数・起動の時間帯などに加えて、お気に入り、迎えた種類数、なでた累計回数、ホームや誕生日の設定、起動の続き方などを組み合わせます。猫ごとの条件は固定で、すべてそろった日だけ候補選びの対象になります。詳細は [ノーマル条件の見直し](normal-conditions-redesign.md) と [猫ごとの条件表](cat-conditions.md) を参照してください。
