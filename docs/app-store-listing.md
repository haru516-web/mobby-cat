## 説明文

```
歩いた数、電池の残り、今日の天気、季節や曜日、時間帯。
いつもの暮らしに合わせて、その日だけの猫「にゃこモビー」と出会えるアプリです。

■ 毎日、3匹と出会う
毎晩20時、その日の条件がそろった3匹の候補が届きます。
その中から1匹を、無料で迎えられます。
たくさん歩いた日、雨の日、朝に開いた日、誕生日。条件の合う日にしか会えない猫もいます。

■ 図鑑を集める
迎えた猫は、図鑑に記録されます。
どんな日に会えるのか、条件を探すのも楽しみのひとつです。

■ 一緒に写真を撮る
カメラで、猫と一緒に写真を撮れます。撮った写真は、写真アプリへの保存や共有ができます。

■ もっと会いたい日は
・お迎え券：候補の中から、もう1匹を確実に迎えられます。
・またたび：その日の候補が1匹ふえます（最大6匹）。
・またたびパス（月額サブスクリプション）：加入中は、毎日の候補が3匹から6匹になり、毎月お迎え券が8枚届きます。

無料でも、毎日1匹ずつ、猫を集められます。
お迎え券は、迎える猫を選べる券です。ガチャのように、確率で結果が決まる課金はありません。

■ 引き継ぎ
Appleでサインインすると、機種変更しても、猫・図鑑・購入したアイテムを引き継げます。メールアドレスや名前は受け取りません。

■ 使う情報について
・歩数：その日の出会いを決めるために、端末の中だけで読み取ります。
・位置情報（任意）：その日の天気を調べるために、おおまかな位置だけを使います。許可しなくても遊べます。
・カメラ：猫と写真を撮るときだけ使います。
・毎日20時のお知らせは、設定でいつでも切れます。
広告の表示やアクセス解析はありません。

■ またたびパス（自動更新サブスクリプション）について
・料金：月額 1,500円（税込）。App Storeに表示される価格が適用されます。
・購入の確定時に、Apple Accountに請求されます。
・期間が終わる24時間前までに解約しない限り、1か月ごとに自動で更新され、Apple Accountに請求されます。
・解約は、iPhoneの「設定」→ 上部の名前 →「サブスクリプション」から、いつでもできます。
・解約しても、迎えた猫は残ります。

プライバシーポリシー：https://nyakomobby-server.mobidou.workers.dev/privacy
利用規約：Apple標準の使用許諾契約（EULA）：https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
```

## 審査用メモ（App Review Information に貼る）

```
【アプリの概要】
歩数・電池・天気・暦などの条件から、毎日3匹の猫の候補を出し、1匹を無料で迎える収集アプリです。ログインは不要で、起動するとすぐ遊べます（匿名のアカウントが自動で作られます）。

【権限の使い道】
・モーションとフィットネス：その日の歩数を、出会いの条件にするために読み取ります（端末の中だけで使います）。
・位置情報（使用中のみ・任意）：その日の天気を調べるために、小数第1位に丸めた位置を、天気予報サービス（MET Norway）へ1日1回送ります。許可しなくても遊べます。
・カメラ：猫と一緒に写真を撮る機能に使います。
・通知（任意）：毎日20時の出会いのお知らせ（端末の中で予約します）。

【アプリ内課金の確認手順】
1. ホームのヘッダーのお迎え券/またたびの表示、またはメニューから「ショップ」を開きます。
2. 商品を選んで「購入する」を押します。
3. 購入の前に、Appleでのサインインが求められます（購入したものと記録を、機種変更で引き継ぐためです）。サインインすると、年齢の区分を選ぶ画面が出ます（毎月の購入上限のため）。選ぶと購入に進みます。
4. サンドボックスの購入が完了すると、お迎え券・またたびが増えます。またたびパスは、加入中の表示になります。
購入の復元：ショップの「購入を復元」から行えます。
※確率で結果が決まる課金（ガチャ）はありません。お迎え券は、候補の中から選んだ猫を確実に迎える券です。

【アカウントの削除】
設定（ホーム右上の「設定」）→「アカウント」→「アカウントを削除する」から、アプリ内で削除できます。

【連絡先】
info@mobby.online
```

## 公開前の確認

- 説明文の「1,500円」は、App Store Connect で設定した価格と一致させる。
- 説明文の条件の例は、`docs/cat-conditions.md`（歩数・天気・電池・時間帯・季節・曜日）と誕生日の機能に合わせてある。条件を増減したら見直す。
- 利用規約を独自のページにしたら、説明文の末尾の行と `TERMS_URL` を差し替える。
- 審査用メモの操作名（「ショップ」「購入を復元」「アカウント」）が、実機の表記と一致するか、実機で確認する。
