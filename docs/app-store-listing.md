## 説明文

```
歩いた数、電池の残り、今日の天気、季節や曜日、時間帯。
いつもの暮らしに合わせて、その日だけの猫「にゃこモビー」と出会えるアプリです。

■ 毎日、条件がそろった猫と出会う
毎晩20時、その日の出会いの条件がそろった猫が候補に並びます。条件をすべて満たしたら、その日の候補に必ず出ます。条件を満たした猫を候補から抽選で外すことはありません。候補は届いた時点ですべて見えます。同じ日・同じ状態なら、顔ぶれも同じです。
ノーマルの猫には、歩数、天気、時間帯、曜日、電池やコレクションなど、猫ごとに決まった条件があります。条件を満たす猫がいない日には、日付で決まる軽い条件のノーマルが1匹加わります。
候補から1匹を、無料で迎えられます。たくさん歩いた日、雨の日、朝に開いた日、誕生日。条件の合う日にしか会えない猫もいます。

■ コレクションを集める
迎えた猫は、コレクションに記録されます。
どんな日に会えるのか、条件を探すのも楽しみのひとつです。

■ 一緒に写真を撮る
カメラで、猫と一緒に写真を撮れます。撮った写真は、写真アプリへの保存や共有ができます。

■ 候補から迎える
お迎え券を使うと、候補の中からもう1匹を選んで迎えられます。条件を飛ばして猫を迎えることはできません。

またたびとまたたびパスは、新しい出会いの仕組みに合わせて準備中です。現在はショップで新規購入を一時停止しています。所持中のまたたびや加入中のパスは記録に残り、購入済み商品の復元・引き継ぎもできます。

■ 引き継ぎ
Appleでサインインすると、機種変更しても、猫・コレクション・購入したアイテムを引き継げます。メールアドレスや名前は受け取りません。
サインインしない場合、迎えた猫と記録は端末の中だけにあり、機種変更やアプリの削除で消えます。サインインせずに購入した場合、お迎え券・またたびは引継ぎコードで、加入中のまたたびパスは「購入を復元」で、新しい端末へ移せます（猫と記録は移せません）。

■ 使う情報について
・歩数：その日の出会いを決めるために、端末の中だけで読み取ります。
・位置情報（任意）：その日の天気を調べるために、おおまかな位置だけを使います。許可しなくても遊べます。
・カメラ：猫と写真を撮るときだけ使います。
・毎日20時のお知らせは、設定でいつでも切れます。
広告の表示やアクセス解析はありません。

■ またたび・またたびパスをご利用中の方へ
新しい出会いの仕組みに合わせて、またたびとまたたびパスの新規購入を一時停止しています。購入済みの残高や加入中の契約は記録に残ります。またたびパスをご利用中の方には、契約内容に応じて毎月お迎え券8枚が付与されます。
加入中のパスは、期間が終わる24時間前までに解約しない限り、1か月ごとに自動で更新されます。解約は、iPhoneの「設定」→ 上部の名前 →「サブスクリプション」からいつでもできます。解約後も、迎えた猫と購入済みの記録は残ります。

プライバシーポリシー：https://nyakomobby-server.mobidou.workers.dev/privacy
利用規約：Apple標準の使用許諾契約（EULA）：https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
```

## 公開前の確認

- 新規購入を再開する場合は、価格と商品説明を App Store Connect の設定に合わせて更新する。
- 説明文の条件の例は、`docs/cat-conditions.md`（歩数・天気・電池・時間帯・季節・曜日）と誕生日の機能に合わせてある。条件を増減したら見直す。
- 利用規約を独自のページにしたら、説明文の末尾の行と `TERMS_URL` を差し替える。
- 審査用メモの操作名（「ショップ」「購入を復元」「アカウント」）が、実機の表記と一致するか、実機で確認する。


ノーマルの出会い条件は、天気・歩数・起動の時間帯などに加えて、お気に入り、迎えた種類数、なでた累計回数、ホームや誕生日の設定、起動の続き方などを組み合わせます。猫ごとの条件は固定で、すべてそろった猫は全員その日の候補に並びます。詳細は [ノーマル条件の見直し](normal-conditions-redesign.md) と [猫ごとの条件表](cat-conditions.md) を参照してください。
