# アプリ内監査（2026-10-25）

対象は `feature/next` のアプリ全体（`app/src` と `App.tsx`）です。コードを全部読んだうえで、Web（iPhone 幅 375pt）で各画面を表示して確認しました。iOS 実機では確認していません。

状態の凡例：✅ 今回修正 / 🔜 未対応（次にやる） / 🎨 Codex の画像待ち（`codex/ui-fixes`）

## 3. まだ直していない改善点

- 🔜 歩数・電池は、その日の候補を作った瞬間の値だけで判定している。20時より後に歩いた分は翌日の判定に入らない（仕様どおりだが、説明はない）。
- 🔜 通知を ON にしたあと、端末の設定で通知を切っても、アプリ内の表示は ON のまま。
- 🔜 ショップの購入ボタンは、テスト版のため押すと無料で付与される。本物の課金をつなぐまで、公開ビルドでは隠す必要がある。
- 🔜 決定済みで未実装のもの（`game-design.md` の 16.）：相棒の3種抽選と再抽選、なでる回数の報酬、ホームに置く猫の選択、Appleサインインの任意連携。
