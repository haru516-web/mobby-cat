# docs の目次

| ファイル | 内容 |
|---|---|
| `game-design.md` | 企画・仕様書（コンセプト、収集ループ、課金、世界機能、MVP） |
| `appearance-catalog.md` | にゃこモビーの名前・出現条件・由来の台帳（企画側の元データ） |
| `growth-plan.md` | 公開に向けた考え方（興味→継続→課金→拡散）と、残りのタスク・改善点 |
| `audit-2026-10-25.md` | アプリ内監査の結果（不具合・UI の問題と、直したもの・残っているもの） |
| `ui-reference/` | 目標とするUIの参考画像4枚（ホーム・図鑑・出会い・世界） |
| `codex/ASSET_LIST.md` | UI画像の完全リスト（ファイル名・サイズ・伸縮の指定） |
| `codex/CODEX_PROMPT.md` | UI画像を Codex に作らせる指示書 |
| `codex/UI_SETTINGS_PROMPT.md` | 設定画面の画像（歯車ボタン）を Codex に作らせる指示書 |
| `codex/AUDIO_PROMPT.md` | BGM（3曲）と効果音（12個）を Codex に作らせる指示書。場面・長さ・形式・ファイル名 |
| `codex/NEW_MOBBIES_LIST.md` | 新しいにゃこモビー100匹の一覧（ID・名前・ビジュアル案） |
| `codex/NEW_MOBBIES_PROMPT.md` | 新しいにゃこモビーを Codex に作らせる指示書 |

Codex に依頼するときは、専用のブランチと worktree を作り、指示書の冒頭に作業フォルダを書く（[README](../README.md) 参照）。
