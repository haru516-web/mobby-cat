# にゃこモビー全体アニメーション

`app/src/data/catalog.ts` の全270体について、各キャラクターの元画像を参照して個別に作成したアニメーションスプライトです。

各IDフォルダに、次の4種類を収録しています。

| フォルダ | アニメーション | 動き |
|---|---|---|
| `peekaboo/` | 目隠し | 両手で目を覆い、長く目を擦ってから元に戻る |
| `fall-back/` | 後ろに転倒 | 後ろへ倒れ、仰向けのまま慌てて手足をばたつかせる |
| `angry-hands/` | 怒り | 両手を上げ、怒った表情で小刻みに振る |
| `sleep-bubble/` | 鼻ちょうちん | 横になって眠り、鼻ちょうちんを膨らませてしぼませる |

## 形式

- ファイル: `<キャラクターID>/<アニメーション>/spritesheet.png`
- RGBA透過PNG、2048×1024px
- 4列×2行、1コマ512×512pxの8コマ
- キャラクターIDと元画像は `app/src/data/catalog.ts`、`app/assets/cats/<ID>.webp` に対応
- 進捗記録: `progress.json`

各キャラクターの個別アトラスから4種類のシートを切り出しています。目隠しは覆った状態と擦る動きを長めにし、転倒後は仰向けで慌てる動きを後半に配置しています。

## 右向き威嚇アニメーション (`hiss-right`)

- ファイル: `<キャラクターID>/hiss-right/spritesheet.png`
- 8コマ、2048×1024px、4列×2行、RGBA透過PNG
- 収録: 270体中254体。未収録IDにはこのファイルがありません。
