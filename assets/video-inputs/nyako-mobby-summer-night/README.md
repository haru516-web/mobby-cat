# にゃこモビー「Summer Night Fast Cuts」素材

このブランチで動画制作に使う固定入力素材です。

## 画像
images/ 内の番号順に使用します。01は空の天井、02〜10は覗き方の異なるにゃこモビーです。

## 音源
audio/summer-night-fast-cuts.m4a は、ユーザー指定の summer-night-fast-cuts.mp4 から音声トラックだけを取り出し、AAC音声を再エンコードせずM4Aへ格納したものです。音源はAAC・48kHz・ステレオ、長さ7.600秒です。別音源への差し替え、トリミング、ループ、速度変更はしないでください。

## 編集タイミング
音源のリズムは約160 BPMです。画像を2拍ごと、0.750秒間隔でハードカットします。1〜9枚目は各0.750秒、10枚目は最後の0.850秒保持し、動画全体を7.600秒にします。60fpsなら各カットは45フレーム間隔です。

## 出力の目安
9:16縦型、1080×1920、60fps、H.264/AACのMP4。静止画の直カットを使い、文字・ロゴ・アプリ画面・追加映像・ズーム・トランジションは入れません。
