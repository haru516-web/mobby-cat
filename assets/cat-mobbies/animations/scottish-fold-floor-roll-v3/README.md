# 床ゴロゴロ v3

12ポーズで横寝から仰向けへ動き、ゆっくり横寝に戻る。各ポーズ200ms、1周2.4秒。光学フローによる動き補間で60fpsにし、3周の7.2秒へ書き出し。

- spritesheet.png：1448×1086、4列3行、1コマ362×362、RGBA透過。左上から行順。
- rolling-smooth-transparent.webm：512×512、60fps、VP9アルファ透過。
- rolling-smooth.mp4：512×512、60fps、確認用の白背景。

内蔵image_genで生成。参照はv2スプライトシート。指示：カメラと大きさを固定し、頭を左・胴体を右に保つ。床に寝たまま背骨の軸でゆっくり揺れる。12段階で傾きを増減し、頭・手足・尻尾が連続して追従。横寝→途中姿勢→仰向け→途中姿勢→横寝で継ぎ目をつなぐ。本体のみ、実際のアルファ透過、床・影・文字・効果線なし。

FFmpeg minterpolateでRGBとアルファをそれぞれ補間して再結合。生成画像と光学フローによる補間のため、手足や毛先に局所的な変形が生じる場合がある。
