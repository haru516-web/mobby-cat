# スコティッシュフォールド：寝返りスプライト v6

1枚の変形方式を取りやめ、別々に描いた8姿勢のスプライトシート方式で作成。

- spritesheet-aligned.png：2048×1024、4列2行、各512px。切り出し後に左右位置と接地位置を合わせた納品シート。
- spritesheet.png：生成元シート、1774×887。
- frames/pose-1.png〜pose-8.png：個別の透過姿勢。
- rolling.mp4：白背景の確認用、512px、8.4秒。
- rolling-transparent.webm：アルファ透過、512px、8.4秒。
- extract.cjs：切り出しと配置調整のみ。画像の変形なし。

再生：1→2→3→4→5→6→7→8→7→6→5→4→3→2。100ms/コマ、1周1.4秒、6周。コンテナ30fpsで各コマを3回表示。別の絵の混合、光学フロー補間、クロスフェードは使わない。

## 姿勢

横寝から肩を上げ、お腹を上へ向け、顔が天井を向き、さらに反対へ寝返って背中が見える。逆順で戻る。前足2本・後足2本・尻尾1本を基準に、回り込んだ手足は胴体の陰へ隠れる。

## 内蔵image_genへの生成指示

元のスコティッシュフォールドにゃこモビーの顔・毛色・折れ耳・カメラの目・腹部の十字キーと丸ボタン2つを維持。頭を左、胴体を右、カメラ固定。床に横たわり、頭から尻尾への軸を中心に横寝→仰向け→反対側へ寝返る8段階を4列2行に描き分ける。最後2姿勢は背中が見え、腹部ボタンは回り込んで隠れる。四肢の自然な重なりは許容するが、足を増やさない。各セルに余白を取り、隣のコマにはみ出さない。実際のアルファ透過、本体のみ。床・影・文字・効果線・ブラー・残像は禁止。

追加修正：各セルの余白を拡大。5コマ目の頭を左・胴体を右に修正し、4と6の間の仰向け姿勢にする。動画化前にシートの姿勢順と接地位置を確認。WebMのALPHA_MODE=1と動画の8.4秒を確認。
