# スコティッシュフォールド ゴロゴロ v5

四肢が固定された単一の基準ポーズから、連続した変形で寝たまま背中を揺らす。前足2本、後足2本、尻尾1本を全フレームで保つ。大きく反対側へ寝返る3Dアニメーションではなく、仰向けに近い姿勢での小さな揺れ。

## 納品物

- rolling-smooth.mp4：確認用白背景、640×512、60fps、約7.2秒。
- rolling-smooth-transparent.webm：VP9アルファ透過、本体のみ、640×512、60fps、7.2秒。
- spritesheet-6-keyposes.png：代表6姿勢、3列2行、1コマ640×512。
- spritesheet-144.png：動画で使った全144枚、12列12行、1コマ640×512。左上から行順。
- frames/：全144枚の透過PNG。1フレーム1/60秒、1周2.4秒。
- base-pose.png：基準ポーズ。
- render.cjs：再生成スクリプト。

## 方法と確認

内蔵image_genで元キャラクターを参照し基準画像を作成。四肢の本数、腹部の十字キーと丸ボタン2つを確認。Node.jsで背中を支点とする連続変形に、前足・後足・頭・尻尾の位相差を付けて144枚を生成。全コマが単一の基準画像を参照し、別ポーズ間の補間、光学フロー、クロスフェード、時間的な画像混合を使わない。透明境界のRGB混入を避けるためアルファを乗算してから再標本化。

6姿勢の一覧で四肢と輪郭を目視確認。動画メタデータで60fps、640×512、WebMのALPHA_MODE=1を確認。ループは周期関数の末尾から先頭へ連続する。

## 基準ポーズ生成プロンプト

参照のスコティッシュフォールドにゃこモビー。クリーム色の毛、折れ耳、金色の目と黒いカメラレンズの目、ピンクの鼻、腹部に黒い十字キーと丸ボタン2つを維持。頭を左、胴体を右にして背中を床へ預け、リラックスした仰向け姿勢。前足2本を胸の上下に、後足2本を腰の上下に離して配置。後足2本のみに肉球、尻尾1本に肉球なし。全身を余白付きで配置。本体のみ、実際のアルファ透過。床・影・小物・文字・効果線・ブラー・二重輪郭は描かない。
