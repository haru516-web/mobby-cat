# 全にゃこモビー「肉球で画面を覆う」アニメ

カタログ270匹分の個別スプライトシートと動画の出力一覧です。

- `manifest.json`: カタログ順の元画像・出力先・作成状況。
- `package-sheet.ps1`: 生成シートの標準サイズ化、フレーム分割、動画書き出し。
- 各IDフォルダ: `spritesheet.png`（透過RGBA、2048×1024、4×2、各コマ512px）、`preview.mp4`（2秒・30fps）、`transparent.webm`。
- 動き: 二足で構える → 二足で飛ぶ → 手前へ接近 → 肉球でレンズを覆う。
- `rea-mobby/` は採用済み修正版。ほかは各キャラの元画像を参照して個別生成。

MP4は透過非対応のため淡い生成り色を背景に合成し、透過素材はPNGとWebMで保持します。

## 進捗

2026-11-06時点で137/270匹が完了。残り133匹を同じ二足立ちの仕様で作成中。

共通プロンプト: 元画像の顔・毛色・模様・耳・尻尾・アクセサリーを保ち、二足で構える→飛んで接近→前足でレンズを覆う8コマのアニメーションにします。
