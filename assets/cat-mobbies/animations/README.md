# にゃこモビー ゴロゴロアニメーション

レア度1（ノーマル）16種、レア度2が127種、レア度3が98種、レア度4が29種、計270種を収録しています。各レア度内は図鑑カタログ順です。各キャラクター名のフォルダーにスプライトシートと動画があります。

## 共通仕様

- 透過PNGスプライトシート：4列×2行、8ポーズ、2048×1024
- ループ動画：8ポーズを順再生し、折り返してつなぐ14フレーム構成、8.4秒、30fps
- WebM：背景透過
- MP4：白背景
- スコティッシュフォールドは採用済みのv6を使用しています。
