# 新規 猫モビー画像

既存のモビー形状を基準に、built-in image_gen で生成した新規キャラクター画像100枚です。全画像をコンセプト案として登録し、生成一覧とプロンプト記録を保存しています。

- 画像: `new/<バッチ>/<ID>.png`（バッチ a〜i）
- 管理: `manifest.json`（名前、出現条件、寸法、SHA-256、生成プロンプト）
- 一覧: `previews/batch-<バッチ>.png`
- 生成記録: `../provenance/prompts-new-<バッチ>.md`
- 形式: 1254×1254、透過PNG
- 作り直し: QAで10枚（うるう、さかさま、やみ、ぶんしん、ひみつ、ともだちづれ、マラソン、ぴょんぴょん、カメラマン、ねむりおう）を再生成

| バッチ | 枚数 | テーマ |
|---|---:|---|
| A | 19 | 電池・歩数・アプリ利用 |
| B | 16 | 曜日・暦・特殊な日 |
| C | 13 | 天気・天文・環境 |
| D | 12 | コレクション・複合条件 |
| E | 12 | 利用国数の記念 |
| F | 10 | 世界共通目標 |
| G | 2 | 旅猫・特別 |
| H | 6 | 個性シリーズ |
| I | 10 | 仮称の追加分 |
| **合計** | **100** | |

## 気になった点

正面向きで立つ構図と、片目・カメラレンズ・十字キー・丸ボタン2つの配置を全体の共通ルールにしています。日付や目標数字が小物に入る猫もあります。小物や衣装を含むため、アプリ表示サイズで細部の見え方を確認してください。

デザイン基準はユーザー指定により `rea-mobby.png` と `uyu-mobby.png` を参照しました。作業環境から指定の D: ドライブが利用できなかったため、同じリポジトリ内の `codex/new-mobbies` 専用 worktree で作業しました。
