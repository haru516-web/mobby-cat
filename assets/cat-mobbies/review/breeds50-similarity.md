# 類似猫の見分け確認 — バッチ j

確認資料: breeds50-before-*-256/512.png（生成前）、breeds50-after-j-*-512.png（生成後）。生成画像と近い既存猫を並べた。

- egyptian-mau-smoke: 黒い短毛に銀色の下毛と控えめなゴーストスポット。Bombay/ロシアンブラックの無地、ペルシャブラックスモークの長毛と区別。
- ocicat-silver: 明るい銀地の小さな実斑点、オシキャット的な均一配置。ベンガルのロゼット、ソコケの樹皮状縞と異なる。
- burmese-blue/champagne: 無地の艶短毛と丸い顔、目色は金。ブルーはロシアンブルー等の緑眼・スリムな顔と色以外でも違う。
- russian-white/black: 白または黒の密なダブルコート、大きな立ち耳、細い輪郭と緑眼で近い白黒猫を区別。
- kijitora/saba-tora/chatora: 日本の短毛雑種の細いマッカレル縞。キジトラは褐色、サバトラは銀灰色と胸の白、茶トラはオレンジと淡い腹部。近い既存のスポット・クラシックタビーと並べて確認。
- sabi-neko: 白斑のない黒橙の短毛マーブル。三毛の白地や白い靴下のあるキャリコと区別。

目視確認: 10匹とも生体の目は1つ（画面左、丸い黒目）とレンズ1つ（画面右）。十字キー1つ、無地丸ボタン2つ、衣装・小物なし。プレビューのサムネイルでも毛色・柄と耳・顔の差が残っている。

- suffolk-lilac: ピンク味のあるライラック短毛、艶、黄緑眼。ブルー/ライラックのバーミーズやオリエンタルと比較。
- tennessee-rex: 赤白の柔らかな波状巻き毛に絹のような光沢。LaPerm等の密な巻き毛と差を確認。
